# 用法一（推荐，在线转换）：
#   打开 https://lvgl.io/tools/fontconverter
#   - Font: 上传 NotoSansSC-Regular.otf（思源黑体 / Noto Sans SC）
#   - Size: 16（再生成一个 20 的用于标题）
#   - Bpp: 4（抗锯齿，16px 下观感明显更好）
#   - Symbols: 复制下面【字符行】粘贴进去
#   点 Convert 下载 .c 文件
#
# 用法二（命令行 lv_font_conv）：
#   见同目录 gen_cn_font.bat
#
# 说明：ASCII（0x20-0x7E）由转换器用 -r 0x20-0x7E 覆盖，不需要放进字符行。
# 以后界面加中文时，把新字补进【字符行】重新生成即可。
