# ============================================================
#  完整中文字库生成方案（用于看小说 / 通用中文显示）
# ============================================================
#
# 【当前状态】main/lv_font_cn_16.c 是用下面「三、生成命令」那行生成的，
#   实际范围 = 32-126,176,183,12288-12351,65281-65374,19968-40869
#   —— 少了 0x2010-0x2027（… “ ” —— 等），所以界面里不能出现 "…"。
#   代码里长文件名省略号已改用 ASCII 的 '~'（见 file_mgr.c 的 elide_name）。
#   想用真省略号：用【推荐范围】那一行重新生成即可。
#
# 【自查工具】python tools/check_font_glyphs.py
#   会列出源码里所有「会显示出来」但字库里没有的字符（结果写入 missing_glyphs.txt）
#
#
# 说明：常用汉字有几千个，逐个列举容易漏字。
#       lv_font_conv 原生支持 Unicode 范围(-r)，直接按范围生成最可靠。
#
# ------------------------------------------------------------
# 一、推荐范围（复制这一行）★已补上弯引号/破折号/省略号
# ------------------------------------------------------------
0x20-0x7E,0xB7,0x2010-0x2027,0x2030-0x203B,0x3000-0x303F,0xFF01-0xFF5E,0x4E00-0x9FA5

# 各段含义：
#   0x20-0x7E        ASCII 可打印字符（英文、数字、半角标点）
#   0xB7             · 间隔号（外国人名：约翰·史密斯）
#   0x2010-0x2027    通用标点：‐‑‒–—― 破折号、‘’“”,„ 弯引号、… 省略号、†‡• 等
#                    ★ 中文小说最常用 “ ” 和 —— 与 … 都在这个区间
#   0x2030-0x203B    ‰ 千分号、 ※ 等
#   0x3000-0x303F    CJK 标点与符号（。、《》、「」、〔〕等）
#   0xFF01-0xFF5E    全角字符（！＂＃＄（）ＡＢＣａｂｃ）
#   0x4E00-0x9FA5    CJK 统一汉字基本区，共 20902 字
#                    —— 覆盖全部简体常用字 + 繁体 + 生僻字，看小说足够
#
# 【踩坑记录】第一版少了 0x2010-0x2027，导致小说里的 “ ” 全部显示成方框。
#             中文正文几乎必用弯引号，这个区间不能省。
#
# ------------------------------------------------------------
# 二、体积估算（16px 单字号）
# ------------------------------------------------------------
#   bpp=4  →  约 2.8 MB   （抗锯齿最细腻，推荐）
#   bpp=2  →  约 1.45 MB  （4 级灰度，尚可）
#   bpp=1  →  约 0.85 MB  （无抗锯齿，毛边明显，不推荐正文）
#
#   当前 app 约 1.4MB，factory 分区 4MB：
#     bpp=4 → 合计约 4.2MB，超出，需要把 factory 扩到 6MB
#     bpp=2 → 合计约 2.9MB，4MB 够用
#
# ------------------------------------------------------------
# 三、生成命令（PowerShell，在字体文件所在目录执行）
# ------------------------------------------------------------
# 方案 A：bpp=4（画质最好，需先把 partitions.csv 的 factory 改成 0x600000）
#
# lv_font_conv --font NotoSansSC-Regular.otf --size 16 --bpp 4 --no-compress -r 0x20-0x7E,0x3000-0x303F,0xFF01-0xFF5E,0x4E00-0x9FA5 --format lvgl -o lv_font_cn_16.c --force-fast-kern-format
#
# 方案 B：bpp=2（体积小，4MB 分区直接用）
#
# lv_font_conv --font NotoSansSC-Regular.otf --size 16 --bpp 2 --no-compress -r 0x20-0x7E,0x3000-0x303F,0xFF01-0xFF5E,0x4E00-0x9FA5 --format lvgl -o lv_font_cn_16.c --force-fast-kern-format
#
# 在线转换 https://lvgl.io/tools/fontconverter 的话：
#   - Symbols 框：留空
#   - Range  框：粘贴上面【推荐范围】那一行
#   - Size / Bpp 按方案选
#
# ------------------------------------------------------------
# 四、注意
# ------------------------------------------------------------
# 1. 生成较慢（两万字），命令行可能要跑 1~3 分钟，属正常。
# 2. 生成的 .c 放进 main/ 后，确认变量名是 lv_font_cn_16
#    （若在线转换默认名不同，把文件名/变量名统一成 lv_font_cn_16 即可）。
# 3. 若体积超标导致编译报错 region `flash' overflowed，
#    就把 partitions.csv 的 factory 改大（8MB Flash 完全可以给 6MB）。
