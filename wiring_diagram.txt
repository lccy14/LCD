================================================================================

                              ┌─────────────────────┐
                              │     ESP32-S3         │
                              │     模组 / 开发板     │
                              │                      │
         LCD 数据线           │  GPIO3  ── LCD D7    │
         (8位并行总线)         │  GPIO6  ── LCD D0    │
                              │  GPIO7  ── LCD D1    │
                              │  GPIO8  ── LCD D4    │
                              │  GPIO17 ── LCD D2    │
                              │  GPIO18 ── LCD D3    │
                              │  GPIO19 ── LCD D5    │
                              │  GPIO20 ── LCD D6    │
                              │                      │
         LCD 控制线           │  GPIO35 ── LCD DC    │  (数据/命令)
                              │  GPIO36 ── LCD WR    │  (写时钟)
                              │  GPIO37 ── LCD CS    │  (片选)
                              │  GPIO21 ── LCD RST   │  (复位)
                              │  GPIO38 ── LCD BLK   │  (背光 PWM)
                              │                      │
         触摸屏 (I2C)         │  GPIO4  ── Touch SCL │  (I2C 时钟, 400kHz)

                              │  GPIO40 ── Touch INT │  (触摸中断)
                              │                      │
         电源                 │  3V3    ── 3.3V      │
                              │  GND    ── GND       │
                              └─────────────────────┘


================================================================================
                         LCD 屏幕 (ST7789, 8位并口 I80)
================================================================================

  ESP32-S3 GPIO          LCD 屏幕引脚
  ─────────────────────────────────────────────────
  GPIO6    ────────────  D0  (数据位0)
  GPIO7    ────────────  D1  (数据位1)
  GPIO17   ────────────  D2  (数据位2)
  GPIO18   ────────────  D3  (数据位3)
  GPIO8    ────────────  D4  (数据位4)
  GPIO19   ────────────  D5  (数据位5)
  GPIO20   ────────────  D6  (数据位6)
  GPIO3    ────────────  D7  (数据位7)
  GPIO35   ────────────  DC  (数据/命令选择, RS)
  GPIO36   ────────────  WR  (写时钟, PCLK)
  GPIO37   ────────────  CS  (片选)
  GPIO21   ────────────  RST (复位)
  GPIO38   ────────────  BLK (背光, PWM 1kHz)
  3V3      ────────────  VCC (电源 3.3V)
  GND      ────────────  GND
  3V3      ────────────  RD  (读引脚, 硬件接高电平)


================================================================================
                         触摸屏 (FT6336, I2C)
================================================================================

  ESP32-S3 GPIO          触摸屏引脚
  ─────────────────────────────────────────────────
  GPIO5    ────────────  SDA (I2C 数据线)
  GPIO4    ────────────  SCL (I2C 时钟线, 400kHz)
  GPIO40   ────────────  INT (触摸中断, 低有效)
  3V3      ────────────  VCC (电源 3.3V)
  GND      ────────────  GND
  (注: FT6336 的 RST 引脚可直接接 3V3 或悬空)

  I2C 地址: 0x38
  内部上拉: 已启用 (代码中 flags.enable_internal_pullup = true)
  无需外部上拉电阻

================================================================================
                         注意事项
================================================================================

  1. LCD 使用 8 位并行总线 (Intel I80 接口), 不是 SPI
  2. LCD RD 引脚必须在硬件上接 3.3V (代码中不控制)
  3. 触摸屏使用内部 I2C 上拉, 无需外部上拉电阻
  4. 背光使用 PWM 控制 (LEDC, 1kHz, 10位分辨率 0-1023)
  5. WiFi 和 BLE 共存已启用 (CONFIG_ESP_WIFI_SW_COEXIST_ENABLE=y)
  6. PSRAM 使用 Quad SPI 模式 (GPIO26=CS, GPIO30=CLK, 固定引脚)
  7. USB 供电需确保 3.3V LDO 能提供足够电流 (建议 ≥500mA)
