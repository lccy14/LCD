                  LCD 屏幕 (ST7789, 8位并口 I80) —— 第二版
================================================================================

  ESP32-S3 GPIO          LCD 屏幕引脚
  ─────────────────────────────────────────────────
  GPIO10   ────────────  D0  (数据位0)
  GPIO11   ────────────  D1  (数据位1)
  GPIO12   ────────────  D2  (数据位2)
  GPIO13   ────────────  D3  (数据位3)
  GPIO14   ────────────  D4  (数据位4)
  GPIO21   ────────────  D5  (数据位5)
  GPIO47   ────────────  D6  (数据位6)
  GPIO48   ────────────  D7  (数据位7)
  GPIO45   ────────────  TE  ( tearing effect, 预留未用)
  GPIO46   ────────────  DC  (数据/命令选择, RS)
  GPIO9    ────────────  WR  (写时钟, PCLK)
  GPIO3    ────────────  CS  (片选)
  GPIO8    ────────────  RST (复位)
  GPIO35   ────────────  BLK (背光, PWM 1kHz)
  3V3      ────────────  VCC (电源 3.3V)
  GND      ────────────  GND
  3V3      ────────────  RD  (读引脚, 硬件接高电平)

  注: 原理图上 IO46 标为 "DC\SPICLK"、IO9 标为 "WR/DC"，是 8080/SPI 双模式的
      复用网络名。代码使用 8080 并口 (esp_lcd i80)，故按 DC=IO46、WR=IO9 配置。
      若硬件跳线为 SPI 模式，需改用 esp_lcd SPI 驱动，不能只改引脚宏。
  ⚠️ GPIO45/46 是 ESP32-S3 的 strapping 引脚，外围不要加强上拉/下拉，
      否则影响上电启动模式。

                    触摸屏 (FT6336, I2C) —— 第二版
================================================================================

  ESP32-S3 GPIO          触摸屏引脚
  ─────────────────────────────────────────────────
  GPIO18   ────────────  SDA (I2C 数据线)
  GPIO17   ────────────  SCL (I2C 时钟线, 400kHz)
  GPIO16   ────────────  INT (触摸中断, 低有效)
  GPIO15   ────────────  RST (复位, 低有效)
  3V3      ────────────  VCC (电源 3.3V)
  GND      ────────────  GND

  第二版把 RST 接到了 MCU：ft6336_init() 会先拉低 5ms 再拉高、延时 20ms
  释放复位，否则芯片不响应 I2C。第一版 RST 直接接 3V3，无此步骤。

  I2C 地址: 0x38
  内部上拉: 已启用 (代码中 flags.enable_internal_pullup = true)
  无需外部上拉电阻


================================================================================
                    SD 卡 (microSD, SDMMC 主机) —— 第二版
================================================================================

  ESP32-S3 GPIO          SD 卡座引脚
  ─────────────────────────────────────────────────
  GPIO39   ────────────  CLK  (SD_SCLK, 主机输出)
  GPIO38   ────────────  CMD  (SD_CMD, 双向)
  GPIO40   ────────────  D0   (SD_DATA0, 1 线模式下唯一的传输线)
  GPIO41   ────────────  D1   (SD_DATA1, 仅 4 线模式启用)
  GPIO36   ────────────  D2   (SD_DATA2, 仅 4 线模式启用)
  GPIO37   ────────────  D3   (SD_DATA3, 仅 4 线模式启用)
  GPIO42   ────────────  SD   (卡座检测/控制, 代码用 SDMMC_SLOT_NO_CD)
  3V3      ────────────  VCC  (电源 3.3V)
  GND      ────────────  GND  (公共地)

  总线模式: 依次尝试 1线40MHz → 1线4MHz → 4线4MHz → 4线40MHz，成功即停
            （见 main/sd_card.c 的 s_try_list）
  实测:     ESP32-S3 的 SDMMC 全部走 GPIO 矩阵（无 IO MUX 专用脚，驱动会打印
            "input line delay not supported"），4 线对 D0~D3 走线延时很敏感，
            D1~D3 走线不等长或没上拉时会 CRC 错误(err 0x109)，此时自动降速/退 1 线
  文件系统: FAT32，挂载点 /sdcard
  上拉电阻: 代码里启用内部上拉；4 线/高速稳定仍建议 CMD、D0~D3 各接 10k 外部上拉
  注意:     卡必须预先格式化为 FAT32，代码不会自动格式化（避免误删数据）

================================================================================
                   功放 MAX98357AETE+T (I2S) —— 第二版
================================================================================

  ESP32-S3 GPIO          功放引脚
  ─────────────────────────────────────────────────
  GPIO6    ────────────  BCLK     (位时钟)
  GPIO7    ────────────  LRC/LRCLK(左右声道时钟, 即 WS)
  GPIO5    ────────────  DIN      (音频数据, 接主控 DOUT)
  GPIO4    ────────────  SD_MODE  (低=关断静音, 高=工作)
  3V3      ────────────  VDD
  GND      ────────────  GND
  扬声器   ────────────  OUTP / OUTN (BTL 差分输出)

  MAX98357A 内部从 BCLK 恢复时钟，不需要 MCLK，也不需要 I2C 配置寄存器。
  暂停时 audio_player 会关断 SD_MODE，避免底噪；开机默认关断，无噗声。
  若硬件把 SD_MODE 直接上拉到 VDD，把 board.h 里该宏改成 GPIO_NUM_NC 即可。

  ⚠️ 原理图上 GPIO1=WS / GPIO2=SCK 是另一组信号，不是功放（现已接麦克风）。
     功放以带 SD_MODE 的 GPIO4~7 这一组为准。


================================================================================
            麦克风 I2S 数字 MEMS (INMP441 / ICS-43432 等) —— 第二版
================================================================================

  ESP32-S3 GPIO          麦克风引脚      说明
  ─────────────────────────────────────────────────────────────────
  GPIO2   ────────────  SCK / BCLK     主控输出位时钟
  GPIO1   ────────────  WS / LRCK      主控输出左右声道时钟
  GPIO42  ────────────  SD / DOUT      麦克风数据输出 → 主控 DIN
  3V3     ────────────  VDD            注意有些模块只支持 1.8~3.3V
  GND     ────────────  GND
  GND(或3V3) ─────────  L/R            声道选择：GND=左(默认)，3V3=右

  走独立 I2S_NUM_1 控制器，与功放 I2S_NUM_0 完全隔离，采样率互不干扰。
  主控做 MASTER 提供 SCK/WS，麦克风做 SLAVE；不需要 MCLK、不需要 I2C 配置。
  每帧 64 个 BCLK (32bit × 2 slot)，固件配成 32bit 立体声读入后取一个 slot
  的高 16 位 → 16bit / 16kHz / 单声道 WAV，写入 /sdcard/REC_0001.wav
  (编号自动递增，不覆盖旧文件)。单次录音上限 5 分钟。

  ⚠️ 录音时固件会先停播放并关断功放 SD_MODE，避免扬声器回授啸叫。
     录完的 WAV 自动出现在音乐播放列表，可直接点播。

  排错（录出来全是噪声或静音时按顺序查）：
    1. L/R 接了 3V3 → 把 board.h 的 MIC_SLOT_RIGHT 改成 1
    2. 电平太小 → 把 mic_rec.c 的 MIC_GAIN 从 2 调到 4~8
    3. 串口有 "MIC: init ok" 但录音电平恒为 0 → 查 SCK/WS 是否接反、
       模块供电、以及 SD 线是否真的接到 GPIO42
    4. 第一版 PCB 不能接麦克风：IO1/IO2 是 SD D2/D3、IO42 是 SD CMD，
       固件在 BOARD_REV=1 时会自动禁用录音功能（按钮变灰）


================================================================================
                         注意事项
================================================================================

  1. LCD 使用 8 位并行总线 (Intel I80 接口), 不是 SPI
  2. LCD RD 引脚必须在硬件上接 3.3V (代码中不控制)
  3. 触摸屏使用内部 I2C 上拉, 无需外部上拉电阻
  4. 背光使用 PWM 控制 (LEDC, 1kHz, 10位分辨率 0-1023)
  5. WiFi 和 BLE 共存已启用 (CONFIG_ESP_WIFI_SW_COEXIST_ENABLE=y)
  6. PSRAM 使用 Quad SPI 模式 (GPIO26=CS, GPIO30=CLK, 固定引脚)；
     第二版占用了 GPIO35~42，因此不能用 Octal PSRAM 的 N16R8 模组
  7. USB 供电需确保 3.3V LDO 能提供足够电流 (建议 ≥500mA)
  8. SD 卡走 SDMMC 主机(非 SPI)，卡需预先格式化为 FAT32；
     按 1线40MHz → 1线4MHz → 4线4MHz → 4线40MHz 依次尝试，只接 D0 也能用
  9. GPIO45/46 是 strapping 引脚，外围避免强上拉/下拉
 10. 麦克风与功放分用 I2S1 / I2S0，不能把 GPIO1/2 与 GPIO6/7 并联共用时钟
 11. 录音为 16kHz 单声道 (32KB/s)，SD 卡在低速档也够写；播放与录音互斥
